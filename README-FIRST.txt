WIRKEBAU CONSULTING WEBSITE

FILES TO COPY INTO YOUR EXISTING GitHub repository:
- index.html
- styles.css
- script.js
- assets folder
- .nojekyll

IMPORTANT:
Keep your existing CNAME file in the repository. Do not delete it.

Publishing with GitHub Desktop:
1. In GitHub Desktop, click “Show in Finder.”
2. Copy the files above into the repository folder.
3. Replace the existing index.html and style.css when prompted.
4. Delete the old style.css after confirming styles.css is present.
5. Return to GitHub Desktop.
6. Enter summary: “Publish Wirkebau Consulting website”
7. Click “Commit to main.”
8. Click “Push origin.”
9. Wait 1–3 minutes, then refresh your website.
